# HDFS_GUI (Web Version)
A simple web-based GUI application built with Python (Flask) and HTML/CSS/JavaScript for interacting with the Hadoop Distributed File System (HDFS).

## Features
- List / view files in HDFS  
- Upload & download files (put/get)  
- Create & delete directories  
- Copy / move files inside HDFS  
- Check cluster status (JPS)  

## Tech Stack
- Python (Flask)  
- HTML / CSS / JavaScript  
- Hadoop HDFS
